# Model Architectures

This project evaluates paired wild-type and variant DNA sequence representations
for predicting experimentally measured changes in PSI (delta PSI).

## 1. Fine-tuned HyenaDNA

- Pretrained backbone: LongSafari/hyenadna-small-32k-seqlen-hf
- Input: Wild-type and variant DNA sequences
- Maximum sequence length: 260
- Fine-tuning: Final two backbone blocks and final normalization layer
- Learning rate (backbone): 1e-5
- Learning rate (regression head): 1e-3
- Regression head: 3 x backbone hidden dimension -> 256 -> 128 -> 1
- Loss: Smooth L1

## 2. Custom SpliceGPT Transformer

- Encoder-only Transformer architecture
- Shared encoder for reference and variant sequences
- 3 Transformer encoder layers
- 4 attention heads
- Embedding dimension: 96
- Maximum sequence length: 260
- Regression head: 288 -> 192 -> 64 -> 1
- Loss: Smooth L1

## 3. CNN

A convolutional neural network trained on paired DNA sequence representations.

## 4. LSTM

A recurrent neural network using paired wild-type and variant sequence inputs.

## 5. DNABERT-2

A pretrained DNABERT-2 encoder with a paired-sequence regression head.

## 6. Ridge Regression

A classical baseline using nucleotide-frequency features from wild-type
and variant sequences.

## 7. Random Forest

A tree-based regression baseline using nucleotide composition features,
sequence differences and sequence lengths.

## Model Availability

Trained model checkpoints are not included in this repository.

Pretrained model weights must be obtained from their respective model
repositories. Experimental checkpoints can be generated by running
the training scripts.

The reported evaluation metrics are available in the results directory.
